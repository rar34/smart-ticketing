<h1>Project Name: Smart Ticketing</h1>
<p>A responsive website from where people can buy ticket for a specific bus. Total 40 seats is available and one can buy maximum 4 tickets.</p>

Live link: https://rar34.github.io/smart-ticketing

<h2>Features</h2>
<ul>
  <li>User can buy maximum number of 4 ticket from this website</li>
  <li>If people buy 4 tickets he or she can apply coupon for discount</li>
  <li>A toast message  will appear if he or she trying to buy maximum number of 4 tickets</li>
</ul>

<h2>Usage technologies</h2>
<ul>
  <li>JavaScript</li>
  <li>TailwindCSS</li>
  <li>Daisyui</li>
  <li>HTML</li>
  <li>CSS</li>
</ul>
